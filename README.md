A compact, **tested** option-pricing library in Python (NumPy + SciPy) with an interactive
Streamlit dashboard. It starts from Black-Scholes, fixes what a plain implementation gets
wrong or leaves out, and is **validated on a real SPY option chain**, not just synthetic data.

![Smile lab on real SPY quotes](https://raw.githubusercontent.com/Samarty-1/black-scholes-plus/main/docs/screenshots/smile-lab-spy.jpg)

| Plain Black-Scholes | BS+ |
|---|---|
| Non-dividend stock only | Continuous yield (stocks, **Black-76** futures, **Garman-Kohlhagen** FX) and **discrete cash dividends** |
| Delta, gamma, vega, theta, rho | Plus **vanna, volga, charm**; American Greeks incl. vega and rho; all checked against finite differences |
| Newton implied vol that diverges in the wings | **Bracketed Newton + bisection** that converges for every arbitrage-free price; an **American** implied-vol solver |
| European exercise only | **American** options on a Leisen-Reimer tree (error ~1/n² vs CRR's oscillating ~1/n) |
| Vanillas only | **Barrier options** (all 8 single-barrier types with rebates), checked against Haug's tables and Brownian-bridge Monte Carlo |
| One flat volatility | **SVI** smiles, an **arbitrage-free SSVI** surface, **Dupire local vol**, and **Heston** with multi-start calibration |
| Assumes clean inputs | Turns a raw **option chain** into a vol surface: cleaning, parity-implied forwards, **de-Americanization** |

## Real-data study: SPY, 2026-10-06

[`docs/spy-study.md`](https://github.com/Samarty-1/black-scholes-plus/blob/main/docs/spy-study.md) fits three models to 1,241 out-of-the-money SPY
quotes over 8 expiries (7 days to 1 year). It is generated by
[`examples/spy_surface_study.py`](https://github.com/Samarty-1/black-scholes-plus/blob/main/examples/spy_surface_study.py) from the snapshot bundled in
`data/`, so every number is reproducible.

| Model | RMSE (vol pts) | Arbitrage-free? |
|---|---|---|
| SVI, per expiry | 0.07 | Not guaranteed: one pair of expiries crosses in the wings (calendar arbitrage) |
| SSVI surface | 1.10 | Yes, by construction |
| Heston | 1.34 | Yes; misses the steep short-dated skew (vol-of-vol hits its bound) |

![SPY smiles](https://raw.githubusercontent.com/Samarty-1/black-scholes-plus/main/docs/spy-smiles.png)

Two things the real data exposed that synthetic tests never would:

- **The textbook put-call-parity regression fails on American options.** On SPY it implied
  negative interest rates (−2% to −49%), because the early-exercise premium of in-the-money
  puts grows with strike. `market.implied_forward` now refuses that regression for American
  chains and takes the discount factor from the T-bill rate instead.
- **Treating American quotes as European costs up to 1.2 vol points at one year.** That is
  more than the SVI fit error. `build_surface(..., american=True)` solves every quote's vol on
  the American tree and re-estimates the forward. It also showed that an apparent butterfly
  arbitrage in the 1-year SVI slice was an artifact of early exercise, not the market.

## Library tour

```python
import numpy as np
import bsplus as bs
from bsplus import heston, svi

# Black-Scholes price and a full set of Greeks (everything is vectorized)
bs.price(42, 40, 0.5, 0.10, 0.20, "call")            # 4.7594  (Hull's textbook example)
g = bs.greeks(100, 100, 0.25, 0.04, 0.25, "put", q=0.01)
g.delta, g.gamma, g.vega / 100, g.theta / 365, g.vanna

# Same engine, other markets
bs.black76_price(19, 19, 0.75, 0.10, 0.28, "put")    # 1.7011  (Haug, futures option)
bs.garman_kohlhagen_price(1.56, 1.60, 0.5, 0.06, 0.08, 0.12, "call")  # 0.0291 (FX)

# Implied vol that does not blow up in the wings
strikes = np.array([20, 80, 100, 125, 400.0])
prices = bs.price(100, strikes, 0.5, 0.03, 0.35, "call")
bs.implied_vol(prices, 100, strikes, 0.5, 0.03, "call")
# -> [0.3500011, 0.35, 0.35, 0.35, 0.35]; the K=20 call is ~$80 of intrinsic and
#    ~1e-12 of time value, so float64 rounding of the price itself limits precision
bs.implied_vol(150.0, 100, 100, 1.0, 0.03, "call")        # nan: above the upper bound

# American put, with discrete cash dividends and the full set of tree Greeks
res = bs.american_price(100, 110, 1.0, 0.08, 0.2, "put", dividends=[(0.25, 1.0), (0.75, 1.0)])
res.price, res.early_exercise_premium, res.delta, res.vega, res.rho

# Barrier option (Haug's reference value)
bs.barrier_price(100, 90, 95, 0.5, 0.08, 0.25, "call", "down-and-out", q=0.04, rebate=3)  # 9.0246

# Heston: a smile that Black-Scholes cannot produce
p = heston.HestonParams(v0=0.04, kappa=2.0, theta=0.04, xi=0.5, rho=-0.7)
heston.implied_vol_smile(100, [80, 100, 120], 1.0, 0.03, p)  # downward equity skew

# Calibrate Heston to a vol surface (swap in your own market quotes)
Ks = np.tile(np.linspace(75, 125, 9), 2)
Ts = np.repeat([0.5, 1.0], 9)
vols = np.concatenate([heston.implied_vol_smile(100, Ks[:9], t, 0.03, p) for t in (0.5, 1.0)])
cal = heston.calibrate(100, Ks, Ts, vols, r=0.03, n_starts=4)
cal.params, cal.rmse_vol

# SVI smile for one expiry, with a butterfly-arbitrage check
k = np.log(Ks[9:] / (100 * np.exp(0.03 * 1.0)))  # log-moneyness vs the forward
fit = svi.fit(k, vols[9:], T=1.0)
fit.rmse_vol, fit.arbitrage_free

# Arbitrage-free SSVI surface across both expiries, and its Dupire local vol
k_all = np.log(Ks / (100 * np.exp(0.03 * Ts)))
surf = bs.fit_ssvi(k_all, Ts, vols).surface
surf.is_arbitrage_free(), surf.local_vol(0.0, 0.75)
```

## How it is validated

118 tests run on every push (Python 3.10–3.13), together with `ruff` and `mypy`:

- **Published reference values**: Hull (BS), Haug (Black-76, Garman-Kohlhagen, American calls,
  all 8 barrier types with rebate).
- **Greeks vs finite differences**: all eight analytic Greeks; American vega/rho vs
  Black-Scholes where early exercise is never optimal.
- **Implied vol round trip** on a 225-point grid (strikes 20–400, 1 day–10 years, vol 3%–200%).
- **Trees**: Leisen-Reimer vs Black-Scholes and a 4,001-step CRR tree; with cash dividends, the
  European tree matches the escrowed closed form; a large dividend triggers early exercise of a call.
- **Barriers**: in + out = vanilla to 1e-10 for every type, and the closed form agrees with
  Brownian-bridge Monte Carlo within 4 standard errors.
- **Heston**: fast Gauss-Legendre pricer vs adaptive quadrature to 1e-6 across 12 stress cases;
  reduces to Black-Scholes as vol-of-vol → 0; agrees with Monte Carlo; calibration recovers a
  synthetic surface.
- **SVI / SSVI / local vol**: SVI recovers known parameters, and a regression test pins the
  wing-extrapolation bug (below); SSVI recovers a known surface to 1e-14 and stays
  arbitrage-free even on deliberately crossed data; local vol of a flat surface is flat, and
  local-vol Monte Carlo reproduces the surface's own prices within 4 standard errors.
- **Market data** (offline, synthetic chains with known answers): the parity regression recovers
  forward and discount on European chains, *fails* on American chains as on SPY, and
  de-Americanizing recovers the forward to 2e-4.
- **Monte Carlo**: within 4 standard errors of the closed form; the control variate cuts the
  standard error from 0.045 to about 0.008 on the same 200k paths.
- **Property-based tests** (Hypothesis): put-call parity, no-arbitrage bounds, monotonicity in
  volatility, implied-vol round trips, American ≥ European, and barrier in/out parity hold for
  randomly generated contracts. A deliberately planted bug (loosened IV tolerance) is caught
  immediately.
- **Headless dashboard tests**: every tab and data source renders without errors.

### Bugs found by checking, and fixed

| Found by | Problem | Fix |
|---|---|---|
| Heston stress test | Fast pricer off by 1.7e-4 at high vol-of-vol | Fourier cutoff now uses both the Gaussian and the exponential decay rate |
| Looking at the dashboard | SVI smile shot up just past the last quote | Vertex kept inside the quoted range: worst extrapolation error on 40 random smiles 53 → 4.3 vol pts |
| Real SPY data | Parity regression gave negative rates | Rate-based forward for American chains, plus de-Americanization |
| Real SPY data | `option_type` from a pandas column was rejected; an array of types with scalar inputs failed | Option type now broadcasts like every other input |

## Limitations

- Heston cannot fit SPY's steepest short-dated skew; jumps or rough volatility would be needed.
- SSVI's sufficient no-arbitrage conditions are binding on SPY (it trades fit for the guarantee).
- The dividend model is escrowed (the standard approximation); barriers are continuously
  monitored with a flat volatility.
- Yahoo Finance quotes are delayed; the bundled snapshot is a methods demonstration.
- This is an educational and research tool, not trading advice.
